창원경일고 - 나의 진로 DNA 찾기 (프로토타입 v1.0)

사용법
1. index.html 파일을 크롬 또는 사파리에서 열어 실행합니다.
2. GitHub Pages에서는 index.html 파일을 저장소 최상위에 올리고 Pages를 활성화합니다.
3. 별도 서버, 외부 라이브러리, 로그인 없이 동작합니다.
4. 진행 중 응답은 해당 브라우저의 로컬 저장소에 저장됩니다.
5. data.json은 내용 검토용 원본 데이터입니다. 데이터만 수정해도 index.html에 자동 반영되지는 않습니다. 재생성 작업이 필요합니다.
6. 공동으로 쓰는 기기라면 다음 참가자 전에 초기화를 눌러야 합니다.

기능
- 24문항 × 4단계 응답 및 6유형 점수 계산
- 육각형 그래프와 유형별 관심 활동 설명
- 120개 직업 카드(자체 제작 설명), 관심 계열과 선택과목 안내
- 직업 검색/분류/즐겨찾기, 탐험패스에 직업 최대 3개 담기
- 관심 과목 선택, 짧은 소감, SVG 결과 저장 및 텍스트 복사

중요한 검수 사항
- 이 검사는 표준화된 직업심리검사가 아니라 행사 체험용 흥미탐색입니다.
- 직업에 연결된 유형, 직업별 과목 연결 및 직업 설명은 편집용 초안이며 학교 차원의 검수가 필요합니다.
- 35개 과목은 2022 개정 교육과정 기반 예시이나 실제 창원경일고 개설 여부는 미확인입니다.
- 행사 교과 부스의 실제 이름/위치 정보는 제공되지 않아 아직 연결하지 않았습니다.
- 학교 교육과정 편제표를 확보하고 행사 부스 데이터 연계 후 정식 배포를 권장합니다.
- iOS/Android 실제 기기별 화면/저장 동작은 현장 기기 테스트가 필요합니다.
